## B题

![image-20260909160755076](C:\Users\zhm\AppData\Roaming\Typora\typora-user-images\image-20260909160755076.png)

本质就是给两点求截距问题，`double t = (y1-y2)*x1/(x2-x1) + y1;`用这个算就行

注意，这个路障是线段不是直线，所以如果 `x1,x2` 在同侧直接continue忽略

如果  `x1==x2` 也直接忽略，没有截距，会出现 除0 错误

剩下的情况，每次取截距 >0 的最小值即可

## K题

![image-20260909161323372](C:\Users\zhm\AppData\Roaming\Typora\typora-user-images\image-20260909161323372.png)

 

类似于最长公共子序列问题

1. 状态设计

`dp[i][j]`  表示考虑前 $i$ 个 **实际按键 ** 和前 $j$ 个 **预期按键**，所能获得的最大分数。

2. 状态转移

$$dp[i][j] = \max(dp[i-1][j], dp[i][j-1], dp[i-1][j-1] + score[i][j])$$

意思是以下三种情况：

***不选第 i 个实际按键、不选第 j 个预期按键、同时选择第  i  个实际按键和第  j  个预期按键***

先预处理出  `score[i][j]` 数组方便一些，表示第 i 个实际按键匹配成第 j 个预期按键的得分





## L题

![image-20260909163243770](C:\Users\zhm\AppData\Roaming\Typora\typora-user-images\image-20260909163243770.png)

重点要看蛇头可以往哪里走：***新蛇头位置不能等于旧蛇身中除了蛇尾以外的任何格子。***

本质上是障碍物位置在变化的寻路问题，

所以要看整条蛇的位置，来反映障碍物的变化



可以用数组存储一下状态

```
{(0, 0), (0, 1), (1, 1)}
```

比如上方表示蛇头在 `(0, 0)`，第二节在 `(0, 1)`，蛇尾在 `(1, 1)`。

蛇身长度固定，状态数量是有限的，所以可以用 `BFS` 搜索。



初始化状态：

从输入中找出：

- `0` 是蛇头
- `1` 是第二节
- `2` 是第三节
- ……



终止状态：

***如果当前状态的蛇头坐标等于苹果坐标，就说明已经到达苹果***



状态转移：

对于当前状态，蛇头位置是 `head`

枚举上下左右四个方向：

1. 计算新蛇头坐标 `new_head`
2. 如果 `new_head` 越界，跳过
3. 如果 `new_head` 等于当前蛇身中**除了蛇尾以外的任意一个格子**，说明会撞到身体，跳过
4. 新状态就是：

```
新蛇头 + 旧蛇身 - 旧蛇尾
```

- 如果 `new_head` 就是苹果，直接输出 `1`
- 否则把新状态加入 `BFS` 队列，继续搜索



终止状态2：如果 `BFS` 队列为空还没有到达苹果，输出 `0`



***注意有一个坑，蛇长度为2的时候，必须要注意题目里说了不能掉头，但是在上面的判断里是允许这种情况的，特判一下即可***
